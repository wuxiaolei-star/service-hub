# 服务说明 · Python Service Hub V2.3

> 本文档描述 V2.3 交付时系统的整体状态。基础与历史增量见
> [服务说明-V2.0](服务说明-V2.0.md)、[服务说明-V2.1](服务说明-V2.1.md)、
> [服务说明-V2.2](服务说明-V2.2.md)；本文仅详述 V2.3 的增量与最终形态。

## 1. 版本定位

V2.3 在认证、资源治理与自动化闭环之上交付**平台体验**三件套：已安装插件成为
可查询可下载的仓库（多机同步基础）、上传支持 SHA256 秒传查重、任务日志从轮询
升级为 SSE 准实时推送。零数据库迁移，协议不变。

## 2. V2.3 新增能力

### 2.1 插件仓库（Hub-to-Hub 同步基础）

- `GET /api/v1/registry/plugins`（viewer）：全部插件→版本→Build 扁平列表
  （plugin_id/plugin_name/version/build_key/runtime_type/target_arch/status/
  package_sha256，确定性排序）；
- `GET /api/v1/registry/download/{build_key}`（publisher+）：流式返回 Build 的
  runtime 归档（`application/zstd`，附件名 `<plugin_id>-<version>-<runtime>.pypkg`），
  写审计 `registry.download`；未落盘/未知 build → 404；
- hubctl：`registry list` / `registry pull <build_key> --output <目录>`（落盘 +
  sha256sum 风格摘要）/ `registry sync --output <目录>`（全量拉取 ENABLED 包）；
- 管理台"仓库"页：列表 + 下载按钮（403 场景明确提示）。

### 2.2 上传秒传查重

- `GET /api/v1/files/by-sha256/{sha256}`（operator+）：命中返回最新 AVAILABLE 文件
  元数据（复用 `open_available` 保证与按 key 查询一致的语义）；非法哈希 422；
- 管理台文件页内置查重块（64 hex 校验、命中显示文件名+可复制 file_id、404 提示
  "库中无此哈希文件"）。

### 2.3 SSE 实时任务日志

- `GET /api/v1/jobs/{key}/logs/stream`（viewer，`text/event-stream`）：
  cursor 游标增量（读尽自动推进避免重复推送）、终态且读尽发 `event: end`、
  300s 连接上限、客户端断开即时回收、流中 Job 被删优雅收尾；
- 管理台：活跃任务自动切 SSE（`useJobLogStream`，可注入 EventSource 工厂便于
  测试），流结束/错误降级回轮询补全量；日志卡与既有轮询语义一致。

## 3. 质量与验收状态

- 开发机门禁（V2.3 完成时）：python 非集成 **273 passed**（registry 11、hubctl
  registry 4、SSE 6 等新增）、ruff/mypy strict（71 文件）通过、web **166 passed** +
  typecheck/lint/build 通过、`docker compose config` 通过；
- Linux AMD64 验收清单见验收报告 V2.3 节（registry 下载一致性、hubctl sync、
  SSE 推送与 end 帧、Web 三块渲染）。

## 4. 已知限制与后续路线

- 分片/断点续传上传延后（backlog）——当前秒传已覆盖大文件重复上传的主要痛点；
- registry 下载的是 runtime 归档（Hub 安装时不保留原始 .pypkg）；
- SSE 为服务端轮询文件实现（单机 SQLite 形态足够）；
- 后续：**V3.0 长期运行 Docker 服务**（服务运行时、生命周期 API、端口注册、
  服务管理页）为路线图暂定终版。
