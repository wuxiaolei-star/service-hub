# 服务说明 · Python Service Hub V3.2

> 本文档描述 V3.2 交付时系统的整体状态。基础与历史增量见
> [服务说明-V2.0](服务说明-V2.0.md) → [服务说明-V3.1](服务说明-V3.1.md)；

## 1. 版本定位

V3.2 在 V3.1 稳定性加固之上交付**日常效率五件套**，消除三视角推演共识的最高频
操作摩擦：失败重跑、列表检索、进度可视化、回调重放、日志查看器增强。
迁移 0008（`jobs.replayed_from` 一列）。

## 2. V3.2 新增能力

### 2.1 Job 重跑

- `POST /api/v1/jobs/{job_key}/rerun`（operator+）：复用原 Job 的
  params_json/inputs_json/version/runtime_type 走 JobService.create 全流程
  （含配额、Build 校验、审计 action=`job.rerun` + detail.replayed_from）；
- 原 Job 非终态 → 409 `JOB_NOT_TERMINAL`；原 Build 已禁用/删除 → 404 透传；
- `JobResponse` 增 `replayed_from: str | null`——链式重跑指向**直接**原 Job；
- 前端：任务详情页终态"按原参数重跑"按钮（→ 跳新详情页）；列表页 FAILED/TIMED_OUT
  行快捷重跑。

### 2.2 任务列表筛选/排序/分页

- `GET /api/v1/jobs` 增查询参数：`status`（多值重复 `status=RUNNING&status=SUCCESS`）、
  `plugin_id`、`limit`（1-200 默认 100）、`offset`；响应增 `total`（同条件 COUNT）；
- 前端：状态 Segmented（全部/运行中/成功/失败/已取消）+ 插件 Select + 服务端分页
  （pageSize=20，`placeholderData` 防翻页闪烁）；
- plugin_id 过滤经 Job→plugin_build→plugin_version→plugin 四表 join，COUNT 用同一
  subquery 保证与列表一致。

### 2.3 进度百分比 UI

- 管理台任务详情页：从 useJobLogStream/useJobLogs 事件中提取最新
  `{type:"progress", percent}` 渲染 antd Progress（非终态时展示）；
- 协议和前端解析已就绪（V2.0 起），本版将其从日志文本提升为可视化组件。

### 2.4 Webhook 回调重放

- `POST /api/v1/jobs/{key}/callbacks/{callback_id}/replay`（operator+）：
  FAILED/EXHAUSTED → 重置 PENDING（attempts=0、清 last_*），scheduler 下轮自动
  重投（已验证真实再投递路径）；PENDING/SUCCEEDED → 409 `CALLBACK_NOT_REPLAYABLE`；
  审计 action=`webhook.replay`；
- 前端：回调表 EXHAUSTED/FAILED 行"重放"按钮。

### 2.5 日志查看器增强

- 关键字过滤（大小写不敏感 contains）；
- ERROR 行红色 / WARNING 行橙色前缀着色；
- "下载日志"按钮：全量分页循环拼接 → `<job_key>.log` 浏览器下载；
- 自动滚动与"恢复自动滚动"保留。
