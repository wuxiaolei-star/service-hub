# 服务说明 · Python Service Hub V4.0-alpha（Phase 1）

> 本文档描述 V4.0-alpha 交付时系统的整体状态。历史增量见
> [服务说明-V2.0](服务说明-V2.0.md) → [服务说明-V3.3](服务说明-V3.3.md)。

## 1. 版本定位

V4.0-alpha 将后端从"单体重构为**最小内核 + FeaturePlugin 体系**"：内核只做
HTTP/DB/调度/事件四件事，所有功能域通过 `FeaturePlugin` 协议自注册。
**零 API 破坏、零业务逻辑改动。**

## 2. 新增架构组件

| 组件 | 文件 | 说明 |
|---|---|---|
| FeaturePlugin 协议 | `kernel/protocol.py` | name/depends_on/models/routers/scheduler_tasks/event_handlers |
| Plugin Registry | `kernel/registry.py` | 拓扑排序 + 依赖闭包校验（不做静默补齐） |
| Event Bus | `kernel/events.py` | 进程内同步 + SQLite outbox 跨进程投递 |
| HubEvent 模型 | `models.py` | outbox 表（迁移 0010） |
| Auth Plugin | `plugins/auth_plugin.py` | 认证/用户/API Key（3 个 router） |
| Files Plugin | `plugins/files_plugin.py` | 文件上传/下载/查重 |
| Jobs Plugin | `plugins/jobs_plugin.py` | 任务全生命周期 + reaper + retention |
| Catalog Plugin | `plugins/catalog_plugin.py` | 计算插件管理 + 仓库下载 |
| Schedules Plugin | `plugins/schedules_plugin.py` | 定时任务 |
| Webhooks Plugin | `plugins/webhooks_plugin.py` | 回调投递 |
| Backup Plugin | `plugins/backup_plugin.py` | 备份/恢复 |

## 3. 关键架构改进

- **main.py 从 17 行硬编码 include_router 改为 Plugin Registry 循环挂载**
- 每个插件声明 `depends_on`（硬依赖）+ `soft_depends_on`（软依赖）
- 内核按 `depends_on` 拓扑排序加载，硬依赖缺失拒绝启动（不做静默补齐）
- 禁用语义 = 行为卸载（路由 404 + 任务注销 + 事件解绑），schema 保留
- 配置两阶段解析：禁用插件的节 → WARN 忽略（不阻断）
- 前置解除了 `jobs.pipeline_run_id → pipeline_runs.id` 反向 FK（改为逻辑引用）
