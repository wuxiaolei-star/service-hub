### 2.2 P1 —— 交付完整性

**T5：服务器端质量门（关键结论未取得）**

- 问题：`.gate-venv` 已建好（含 5 个 workspace 包 + pytest/ruff/mypy），但首跑
  **在收集阶段中断** —— `tests/plugins/test_nc_to_shp.py` 模块顶层 `import h5py`，
  venv 没装 → 1 个 error 使全量收集失败。
- 这顺带暴露一个健壮性缺陷：**缺测试依赖不该让整个套件无法收集**。
- 方案（推荐 B，A 为保底）：
  - **B**：给 `tests/plugins/test_nc_to_shp.py` 加 `pytest.importorskip("h5py")`
    （同步提交仓库，修健壮性缺陷）；
  - **A**：给 `.gate-venv` 补装 `h5py`（pip ~30 kB/s，预计 3~8 分钟）。
  - 两者都做最稳：先 B 保证可收集，再 A 让该模块真正跑起来。
- 完成判据：服务器 `pytest -m "not integration"` 完整跑完，**确认本机那 5 个
  环境性失败（4× wsl.exe 黑名单 + 1× symlink 静默失效）在真机 Linux 通过**。

- 服务器时间 2026-09-19；时区操作时注意日志时间戳为 GMT+8。
- 本机沙箱**禁止 SSH 转发到 18000**（19123/28000 可用）——要直连后端调试时，
  在服务器本机 `curl 127.0.0.1:18000` 或经 8443 外网走。
